# StudyMap Beta 1

## Beta 1 の変更点

- 個人名・兄弟別の入口を廃止し、トップを「小学生コース」「中学生コース」に変更
- `elementary/` と `junior/` を追加し、コース別URLを直接共有可能に変更
- 旧 `users/younger/`・`users/older/` は新コースへ自動転送して互換性を維持
- スマホを最優先に、iPad・PCにも対応するレスポンシブ調整を実施
- PWA用のmanifest、アイコン、Service Workerを追加
- iPhone/iPadのホーム画面追加と、対応ファイルのオフラインキャッシュに対応
- 日本地理（学ぶ・練習・チャレンジ）と共通BGM・効果音の既存構成を維持
- 名産品学習画面に残っていた、存在しない旧BGM要素を参照するコードを削除

## コース別URL

GitHub Pagesの公開URLが `https://ユーザー名.github.io/StudyMap/` の場合：

- 小学生コース: `https://ユーザー名.github.io/StudyMap/elementary/`
- 中学生コース: `https://ユーザー名.github.io/StudyMap/junior/`

## BGMについて

このZIPには著作権上の理由からBGM実音源が含まれていません。従来どおり、利用する音源を次の名前で配置してください。

`assets/audio/bgm.mp3`

効果音はブラウザで生成する方式のため、追加ファイルは不要です。

## 公開後の確認

1. トップから小学生・中学生の両コースを開く
2. コース別URLを直接開く
3. 小学生コースから日本地理を開き、4分野の学ぶ・練習・チャレンジを確認
4. BGM・効果音のON/OFFとページ移動後の状態保持を確認
5. iPhoneのSafariで「共有」→「ホーム画面に追加」を実行
6. ホーム画面のアイコンから全画面表示で起動することを確認

PWAの動作確認は、ローカルファイルを直接開くのではなく、GitHub PagesなどHTTPS上で行ってください。

## 日本地理・名産品データ

- **正本は `packages/japan/data/specialties.js`**。学習画面はこれだけを読み込みます。
- 47都道府県、各3項目（計141項目）。`code` は1〜47の文字列、`prefecture`・`region` と `items` を持ちます。
- 各項目は `name`, `category`, `image`, `description` を持ちます。分類は管理用で、カードには表示しません。
- カードは「写真 → 名称 → 短い1文の説明」。狭い画面では説明を折り返します。
- 北海道・青森・岩手の既存データ・写真・出典は維持しています。残り44都府県は農水産物・工芸品・郷土料理などから代表例を選定しました。
- 特定の教科書・版との照合は未実施です。使用する教科書に合わせ、項目と写真の被写体を確認してください。生産順位など変動する数値は使っていません。

### 写真の追加手順

1. `docs/specialty-images.md` の候補名を確認します。命名は `都道府県の英字名_品目の英字名.jpg`（小文字・単語区切りは `_`）です。実ファイル形式と拡張子を一致させてください。
2. 教科書に沿った被写体の実写写真を選び、再配布・公開が許可されたライセンスを確認します。教科書の写真そのものに転載許可があるとは限りません。イラストは使いません。
3. 写真を `packages/japan/images/specialties/` に置き、該当する `image` にファイル名を設定します。未用意なら `""` のままにします。
4. `packages/japan/image-credits.html` に、対象項目・作者・出典ページURL・ライセンス名とURL・加工の有無を記録します。
5. 学習画面で写真・名称・説明・出典を確認します。画像の空欄や読込失敗は「写真なし」と表示します。

### 古いJSONについて

`packages/japan/data/specialties.json` は更新停止した旧データとして保存しています。学習画面と事前キャッシュでは使用しません。JSから同期する対象でもありません。今後の編集はJSだけで行ってください。
