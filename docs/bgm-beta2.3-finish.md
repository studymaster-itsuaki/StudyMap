## 公開手順

1. 変更8 HTML、core/bgm.js、新規core/bgm.css、service-worker.jsを一緒に公開する。core/bgm-diagnostic.jsの削除も反映する。testsと本書は記録用。新CSSの公開漏れはSWインストール失敗になるため注意。
2. 通常のGitHub Pagesの公開手順をユーザー側で実施し、配信完了を待つ。学習データを保持するためサイトデータは消さない。
3. iPhone Chromeでオンラインのトップを開き、読み込み完了後に再読み込みする。古い表示が残る場合はトップURLに ?release=20261013-2 を付けて開き、読み込み完了後にもう一度再読み込みする。
4. 配信ファイルにbgm-final-20261013-2、bgm.css?v=20261013-2、SW audio-v5が含まれることを確認する。サーバーのキャッシュに旧版が残る場合は反映を待つ。ローカル変更だけでは公開先は更新されない。

## iPhone Chrome最終確認

1. トップでONにし、ON文字と配色を確認。小学生→日本地理→学ぶ・練習へ移動し、停止してもON表示を保ち、非リンク領域タップで再開する。
2. 中学生、ジャンル、名産品学習、画像クレジットでもボタンと診断パネル撤去を確認。小さい画面でもON/OFF文字が見えることを確認。
3. 再生済みページへ戻る・進むスワイプ後もON設定を保持することを確認。音の復帰はブラウザの復元状態に依存し、停止していればタップで再開する。
4. 再生待ち中もボタンを1回押すとOFFになる。非リンク領域タップ、再読み込み、別画面、戻る・進むでもOFFを維持する。
5. 効果音ON/OFFと正解・不正解音、問題進行、学習記録を確認する。
